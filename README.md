# Flood Sim — แบบจำลองแม่น้ำ + การไหล 3 มิติสำหรับทดสอบเรือดันน้ำ (Python + CUDA)

โปรแกรมมี 2 ส่วน

1. **แม่น้ำ (1D)**: กำหนดรูปทรงแม่น้ำ (ระยะทาง ความยาว ความชัน ความคดเคี้ยว หน้าตัด) หรือนำเข้า KML/KMZ/GPX/GeoJSON/CSV
   แล้วดูว่าการไหลที่ระดับน้ำต่าง ๆ ต่างกันอย่างไร (Q, ความเร็ว, Froude, แรงเฉือน, เวลาไหลผ่าน) — ใช้เลือกระดับน้ำและอัตราการไหล
2. **ช่วงลำน้ำสั้น 3 มิติ (GPU)**: จำลองการไหล 3 มิติรอบ **เรือดันน้ำ** แบบต่าง ๆ ที่จอดอยู่ในลำน้ำ
   เปรียบเทียบกับกรณีไม่มีเรือ: ระดับน้ำ, ระยะของสายน้ำ, ความเร็วผิวน้ำ, แรงเฉือนท้องน้ำ (กัดเซาะ), อัตราการไหลที่เพิ่มได้

## วิธีเปิดโปรแกรม

```bash
python -m floodsim
```

หรือดับเบิลคลิก `run_floodsim.bat` — ติดตั้งไลบรารีครั้งแรกด้วย

```bash
pip install -r requirements.txt
```

## แบบจำลอง 3 มิติ

- **Lattice Boltzmann D3Q19 + LES (Smagorinsky)** เขียนเป็น CUDA kernel เฉพาะ (`floodsim/lbm3d.py`)
  ทดสอบบน RTX 5070 Laptop: ~550–900 ล้านเซลล์/วินาที (ไม่มี GPU จะใช้ Numba บน CPU ซึ่งช้ามาก)
- ทางเข้า: อัตราการไหลจากแบบจำลอง 1D ที่ระดับน้ำที่เลือก (โปรไฟล์กำลัง 1/7 ตามความลึก, ความเร็วเฉลี่ยแต่ละคอลัมน์
  ∝ h^(2/3) ตามแมนนิ่ง), ทางออก: ความดันคงที่
- **wall model**: ท้องน้ำ/ตลิ่งมีแรงเสียดทาน τ = ρ·g·n²·U²/h^(1/3) ตามแมนนิ่ง (U = ความเร็วเฉลี่ยตามความลึกของคอลัมน์นั้น)
  ตัวเรือใช้กฎลอการิทึม (ผิวเรียบ ks 2 มม.) — ทำโดย bounce-back ที่มีความเร็วไถลขนานผนัง ซึ่งคำนวณให้โมเมนตัม
  ที่ถ่ายให้ผนังเท่ากับแรงเฉือนเป้าหมาย; ปิดได้ในหน้าจอหรือ `--no-wall-model`
- ผิวน้ำแบบ rigid lid — ระดับน้ำคำนวณจากความดันใต้ผิวน้ำ (เหมาะกับแม่น้ำที่ราบ Froude ต่ำ)
- เรือ: ตัวเรือเป็นของแข็ง (กล่องหัวเรียว จอดนิ่ง), ใบพัดเป็น actuator disk ที่มีแรงขับ
  คำนวณจากกำลังเครื่องและขนาดใบพัด (หรือใส่แรงขับจริงเอง), ปรับมุมกด ความลึก ตำแหน่ง จำนวนใบพัดได้

### ชนิดเรือที่ตั้งไว้ (แก้ไขค่าได้ทั้งหมด)

| ชนิด | ใบพัด | กำลัง/ใบพัด | หมายเหตุ |
|---|---|---|---|
| เรือหางยาว | 0.30 ม. เอียง 12° ลึก 0.35 ม. | 75 kW | ใบพัดเล็กหมุนเร็ว |
| เรือเครื่องท้าย (outboard) | 0.36 ม. | 110 kW | ใบพัดแนวนอน |
| เรือลากจูง/เรือผลักดันน้ำ | 2 × 1.2 ม. ใต้ท้ายเรือ | 300 kW | ขนาดใหญ่ |
| เครื่องผลักดันน้ำบนทุ่นลอย | 1.6 ม. | 30 kW | ใบพัดใหญ่หมุนช้า แรงขับต่อกำลังสูง |
| เครื่องฉีดน้ำแรงดันสูง | 4 หัวฉีด 100 บาร์ (~141 ม./วิ) | 25 kW | แรงขับต่อกำลังต่ำมาก (~10 N/kW) |
| เครื่องฉีดน้ำแรงดันปานกลาง | 4 หัวฉีด 10 บาร์ (~45 ม./วิ) | 25 kW | ~31 N/kW |
| ม่านน้ำความเร็วต่ำ | 4 ท่อ ~1.3 ม. พ่น 3 ม./วิ | 25 kW | ~467 N/kW (สูงสุด) |
| กำหนดเอง | – | – | – |

หัวฉีด: ตั้งค่า "แรงดัน (บาร์)" > 0 → ความเร็วสายน้ำ v = √(2Δp/ρ), แรงขับ T = 2ηP/v, ขนาดหัวฉีดคำนวณให้อัตโนมัติ;
"มุมฉีดกระจาย ±θ" แบ่งสายน้ำเป็น 3 ทิศในแนวราบ

ค่าเหล่านี้เป็นค่าประมาณเพื่อเริ่มต้น ควรใส่ข้อมูลจริงของเรือที่จะทดสอบ

### การทดสอบเรือแนะนำ 6 แบบ (รันอัตโนมัติ)

1. ชนิดเรือ — แบบไหนดันน้ำได้ดีที่สุด
2. จำนวนเรือ — เพิ่มเรือแล้วได้ผลเพิ่มเท่าไร
3. ระดับน้ำ — เรือได้ผลต่างกันอย่างไรเมื่อน้ำต่ำ/สูง
4. มุมใบพัด — กดใบพัดลงมากน้อยแค่ไหนดี (แลกกับการกัดเซาะท้องน้ำ)
5. การจัดแถวเรือ — เรียงขวางหรือเรียงตามลำน้ำ
6. เครื่องฉีดน้ำ/ม่านน้ำ เทียบกับใบพัด ที่กำลังเท่ากัน (300 kW)

ผลแต่ละกรณีมี "ลดระดับน้ำได้ ซม. ต่อ 100 kW" และ "kW ต่อการลด 1 ซม." สำหรับเปรียบเทียบความคุ้มค่า

### แท็บผลลัพธ์

| แท็บ | สิ่งที่ได้ |
|---|---|
| จำลอง 3D (GPU) | ระนาบแนวนอน, แนวตัดตามยาว, หน้าตัดขวาง (ลูกศรแสดงการไหลวน), ความเร็ว/ระดับน้ำตามแนวลำน้ำ |
| มุมมอง 3D | ภาพ 3 มิติ ตัวเรือ ใบพัด และอนุภาคที่ไหลไปกับน้ำ (หมุนด้วยเมาส์) |
| ผลเปรียบเทียบเรือ | ตาราง + กราฟเปรียบเทียบทุกกรณี และสรุปเป็นข้อความ |
| ระดับน้ำ (1D) / รูปทรงแม่น้ำ | การวิเคราะห์แม่น้ำ 1 มิติ และ 5 การทดลองรูปทรงแม่น้ำ |

ส่งออก: รูป PNG, ผลเปรียบเทียบ CSV, **สนามความเร็ว 3D เป็น .vtk** (เปิดใน ParaView เพื่อดู streamline/isosurface), KML

## โหมดอัตโนมัติ

```bash
python -m floodsim --boat-test 1 --out results
```

ตัวเลือก: `--exp 1-5` (หน้าตัดจากการทดลองรูปทรงแม่น้ำ), `--level 3` (ความลึก ม.), `--file samples/sample_river.csv`,
`--max-cells 1000000`, `--length 150`, `--no-wall-model` — บันทึกภาพการไหลของทุกกรณี (`slices3d_caseN.png`,
`view3d_caseN.png`, รายชื่อใน `cases.txt`)

## ข้อจำกัดที่ควรรู้

- ผิวน้ำ rigid lid: ไม่จำลองคลื่นหรือการยุบตัวของผิวน้ำรอบใบพัดตื้น ๆ
- ใบพัดที่เล็กกว่า 3 เซลล์ถูกขยายโดยคงแรงขับเท่าเดิม → ความเร็วใกล้ใบพัดต่ำกว่าจริง แต่โมเมนตัมและผลระยะไกลถูกต้อง
- ไม่จำลองการหมุนวน (swirl) ของสายน้ำหลังใบพัด
- wall model: ในช่องสี่เหลี่ยม แรงเสียดทานตรงกับแมนนิ่ง ±10% (n 0.02–0.03) แต่ท้องน้ำขรุขระมาก (n ≥ 0.045)
  ได้ต่ำกว่าจริง ~30%; ในหน้าตัดคางหมูที่ตลิ่งเป็นขั้นบันได ช่วง ~100 ม. แรกจากทางเข้ายังสูงกว่าแมนนิ่ง 1.3–1.5 เท่า
  (การไหลยังปรับตัว) ส่วนท้ายช่วง ~1.1 เท่า (เดิมไม่มี wall model 1.3–2 เท่า)
- ใบพัดที่ถูกขยายให้ ≥3 เซลล์อาจซ้อนกับแนวท้ายเรือ ทำให้แรงดูดหน้าใบพัดกระทำกับท้ายเรือมากเกินจริง (thrust deduction)
  ลดได้โดยเพิ่มจำนวนเซลล์ (`--max-cells`) หรือย้ายใบพัดออกห่างท้ายเรือ
- ช่วงจำลองสั้น จึงประมาณผลต่ออัตราการไหลระยะไกลด้วยสมดุลโมเมนตัม ("ถ้าวางกลุ่มเรือซ้ำทุก ... กม.")
- ท้องน้ำเป็นขั้นบันไดตามกริด ความขรุขระละเอียดไม่ได้จำลอง — ผลเหมาะกับการ **เปรียบเทียบ** แบบเรือ/การจัดวาง
  มากกว่าการทำนายค่าสัมบูรณ์ ควรสอบเทียบกับการวัดจริงก่อนใช้ตัดสินใจ

## โครงสร้างไฟล์

```
floodsim/
  lbm3d.py         ตัวแก้สมการ 3 มิติ (CUDA kernel + Numba)
  reach3d.py       เรือ/ใบพัด, ช่วงลำน้ำ, การรัน, สรุปผล
  boat_tests.py    การทดสอบเรือแนะนำ 5 แบบ
  geometry.py      สร้างแม่น้ำจำลอง / ประมวลผลเส้นแม่น้ำที่นำเข้า
  io_formats.py    อ่าน KML/KMZ/GPX/GeoJSON/CSV, ส่งออก KML
  hydraulics1d.py  สมการแมนนิ่ง 1D, rating curve
  experiments.py   การทดลองรูปทรงแม่น้ำ 5 แบบ (1D)
  gui.py           หน้าจอโปรแกรม
_archive_2d/       แบบจำลอง 2 มิติเดิม (เลิกใช้แล้ว เก็บไว้อ้างอิง)
samples/           ไฟล์แม่น้ำตัวอย่าง
```
